# Covariance routing PoC

Run commands from this directory using the Python environment in the [setup instructions](../README.md#run-the-poc).

## Models and evaluation

Both routers use 56 lagged features: one VIX level, one 21-day SPY volatility, nine sector volatilities, and 45 upper-triangular sector covariance entries. Their three regression targets are the natural logs of the sample variances of each expert's next 21 daily gross buy-and-hold GMV returns. The variance floor is `1e-12`.

The 60/20/20 training, validation, and test split is chronological and uses disjoint label windows. Scaling and parameter updates use the training windows. Validation log-variance MSE selects the MLP checkpoint via early stopping. Validation net portfolio volatility selects the Ridge alpha and each router's temperature. On test, both routers share dates and trading-cost assumptions with Historical, EWMA, Ledoit–Wolf, Static Blend, and Equal Weight.

## Price inputs

- `--demo` generates deterministic synthetic prices for an offline run.
- `--yahoo` downloads nine sector ETFs, SPY, and the VIX index level via yfinance. The default request starts on 2014-01-01 and ends on 2026-11-12 (exclusive). The downloader writes the cleaned CSV, its SHA-256, and per-ticker gap counts to `data/`.
- `--csv PATH` reads a single-header file with `Date,XLB,XLE,XLF,XLI,XLK,XLP,XLU,XLV,XLY,SPY,VIX`. Use adjusted closes for the ETFs and index levels for VIX. The original repository's raw Yahoo CSV has a multi-row header and requires conversion to this schema before use.

## Outputs

Each run writes `test_metrics.csv`, `test_daily_returns.csv`, `test_rebalance_weights.csv`, `run_metadata.json`, and `viva_dashboard.html`. Open the HTML file in a browser to see the comparison and both learned expert-weight series. Pass `--out results_custom` to keep a run separate. The route is refit from its training windows on each run.

The data snapshots and reports generated by this PoC are local run artifacts. Archive the price CSV and its download metadata together when reproducing a particular market run.
